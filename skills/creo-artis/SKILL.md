# Creo Artis

Instructions: Start by using Lege Voluntatem to expand on the user's request. Then, using the output from Lege Voluntatem, use Conceptio Artis Maior for the main concept of the artwork, Then follow the instructions in Elige et Illumina. And finally design each detail with Sculpe Singula. Then create a detailed AI art prompt for it.
