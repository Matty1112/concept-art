# Sculpe Singula

Instructions: For each key detail that was chosen, start by using Conceptio Artis to come up with a concept for each detail. For example, if it's a storm warrior, what kind of weapon would it be, and what are its main detail? Choose each concept with Conceptio Artis minor.
Then when each key detail is chosen as concepts, start flesh out each key detail bit by bit, starting from the most fundamental details, down to the auxilary components of the detail.
